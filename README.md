# Teste do DualSense

Página única para testar os motores de vibração, a pressão e os efeitos dos gatilhos adaptativos (L2 e R2) e a barra de luz de um controle DualSense.

Abra no Chrome ou no Edge (o Firefox e o Safari não têm WebHID): https://welingtonfidelis.github.io/teste-dualsense/

Funciona pelo cabo USB ou pelo Bluetooth. Clique em **Conectar** e escolha o controle na lista.
